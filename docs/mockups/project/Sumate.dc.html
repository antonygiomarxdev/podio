sumate

Solo aparece quien se anota. Nadie puede agregarte ni sacarte: lo hacés vos con tu propio PR.

Sumate en 3 pasos

  1. 1

    Hacé fork de este repositorio.

  2. 2

    Agregá tu archivo members/tu-usuario.json

    { "github": "tu-usuario", "country": "NI" }

    country es el código de dos letras de tu país (AR, BO, BR, CL, CO, CR, CU, DO, EC, GT, HN, MX, NI, PA, PE, PR, PY, SV, UY, VE).

  3. 3

    Abrí un Pull Request. Un check automático lo valida; cuando se acepta, aparecés en el podio al día siguiente.

Sumate al podio

¿Querés salir?

Borrá tu archivo con un PR. Es el mismo camino: lo abrís vos y se acepta.

Un PR solo puede tocar el archivo de quien lo abre. Si toca el de otra persona, se rechaza.
