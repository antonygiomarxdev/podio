Selector para limitar el ranking a un país, con la opción "Todos" (D-29).

Quien consume provee: los 20 países aceptados (AR, BO, BR, CL, CO, CR, CU, DO, EC, GT, HN, MX, NI, PA, PE, PR, PY, SV, UY, VE), tengan miembros o no, y cuáles tienen miembros. Cada opción se muestra como bandera emoji más el nombre del país en español.

- La primera opción es "Todos"; el resto va ordenado alfabéticamente por el nombre en español (Argentina, Bolivia, Brasil, Chile… Uruguay, Venezuela).
- Un país sin miembros sigue en la lista, con el sufijo " · sin miembros todavía". Al elegirlo se muestra el estado vacío que invita a sumarse.
- Etiqueta "País" en `muted`; el `select` en `surface`, texto `text`, borde `border`, radio `radius-sm`.
- Al elegir un país las posiciones se cuentan dentro de ese país.
- El foco se ve con el anillo de `amber`; no lo quites.
